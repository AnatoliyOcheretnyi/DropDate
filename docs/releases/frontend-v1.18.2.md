# Кіноатлас із постерами та українські назви

Патч frontend 1.18.2 оновлює «Світ кіно», покращує відображення українських перекладів і стабільність персональних рекомендацій.

- Країни на глобусі заповнюються мозаїкою постерів. Кількість залежить від площі; для Росії — до 24 постерів.
- Постери приглушені, кордони виразніші. Наведення повертає повну яскравість країні, на телефоні підсвічується вибір. Зайву спливаючу картку прибрано.
- Каталог для всього глобуса завантажується одним запитом. Вибір країни показує три фільми; повний список відкривається окремою кнопкою.
- Постери завантажуються обмеженими паралельними пакетами, щоб великі країни швидше отримували повну мозаїку.
- Прев’ю фільму залишається відкритим, доки кнопка має фокус, і не закривається при переході курсора до його дій.
- Українські переклади використовуються в деталях, пошуку, збережених списках і прев’ю; автоматично перекладені поля мають відповідну позначку.
- Перемикання персональних рекомендацій зберігає висоту секції та плавно змінює картки. Прибрано великий блок помилки налаштування смаку.
- У верхній навігації «Головна» замінена на «Мій список»; логотип веде на головну.

Супутній API: backend 1.17.2. Реліз проходить lint, перевірку TypeScript, модульні тести, production build і браузерні перевірки для десктопа та телефона.
