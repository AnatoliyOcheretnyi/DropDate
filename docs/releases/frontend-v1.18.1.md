# Надійне збереження та кінознахідки друзів

Патч frontend 1.18.1 виправляє мовчазні помилки збереження й оновлює взаємодію зі списками та друзями.

- Автоматичне поновлення сесії, послідовне збереження змін одного тайтлу, видимі помилки та повторні спроби. Черга незбережених змін переживає перезавантаження поточної вкладки.
- Плавне перемикання популярного та оновлення персональних добірок без заміни всього ряду скелетоном.
- Компактні фільтри бібліотеки під час прокручування й кнопка повернення догори.
- Клікабельні картки людей, автоматичні повторні спроби завантаження та зрозумілі повідомлення про проблеми зі з’єднанням.
- Оновлена сторінка друзів: постери, спільні тайтли, пошук, сортування, вкладки запитів та підтвердження видалення.
- Стрічка активності з постерами, оцінками друзів і кнопкою ⓘ для швидкого додавання у власні списки. Фільтри оцінок, доданих тайтлів і персональних порад.
- Виправлено фотографію режисера; прибрано зайве прев’ю з результатів пошуку та додано резервні шрифти.

Перевірки: lint, TypeScript, модульні тести, production build та браузерні сценарії для комп’ютера й мобільного. Супутній API: backend 1.17.1.

Реліз не відновлює тайтли, які не були збережені до встановлення цього виправлення.
