# Постійний каталог кіноатласу та українських перекладів

Патч backend 1.17.2 зберігає переклади й постери кіноатласу в PostgreSQL, щоб вони переживали перезапуски сервера.

- Додано постійне збереження автоматичних перекладів назв і описів з походженням полів, повторне використання перекладів та українських пошукових відповідників.
- Запити перекладу передають лише потрібні поля, об’єднують назви в пакети й враховують обмеження Gemini. Додано інструкції щодо економії токенів.
- Публічний `GET /world/atlas` повертає каталог постерів усіх країн із підтримкою ETag. Запит не використовує Gemini.
- Фонова джоба заповнює каталог і оновлює прострочені записи раз на місяць. При збоях зберігається попередній набір; lease у БД захищає від одночасного оновлення кількома серверами.
- Для Росії зберігаються до 24 унікальних постерів із двох сторінок TMDB; інші країни використовують одну сторінку й до 12 постерів у каталозі.
- Захищений `POST /jobs/world-atlas` ставить оновлення в чергу; додано щомісячний GitHub workflow.

Потрібні міграції `024_title_translations.sql`, `025_world_atlas.sql`, `026_world_atlas_large_country.sql`. Вони вже застосовані до поточної налаштованої БД; нові середовища повинні виконати `backend:migrate` перед запуском. Для зовнішньої джоби використовуються наявні `JOBS_ENDPOINT` і `JOBS_ACCESS_TOKEN`.

Супутній інтерфейс: frontend 1.18.2. Перевірки релізу: Go vet, модульні тести, race detector і збірка. Збереження каталогу та lease додатково перевірені в ізольованій схемі PostgreSQL.
