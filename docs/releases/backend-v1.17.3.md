# Повніші добірки кіно країн

Патч backend 1.17.3 повертає до 60 фільмів у звичайних добірках «Світ кіно» замість обрізання до 18.

- «Найкращі», «Популярні» та «Перлини» використовують повний набір із трьох сторінок discovery; кількість цих запитів не зростає.
- Збагачення метаданими зберігає обмеження паралельності й часу. Фільтри та виключення можуть зменшувати кількість результатів.
- Для персональних добірок залишаються ліміти 30 кандидатів перед ранжуванням і 18 результатів; бюджет Gemini не змінюється.
- Додано перевірку 60 результатів і відсутності повторів між сторінками для трьох режимів каталогу.

Нових міграцій та налаштувань не потрібно. Супутній інтерфейс: frontend 1.18.3. Перевірки релізу: Go vet, модульні тести, race detector і збірка.
