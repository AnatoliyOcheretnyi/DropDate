# Постери у стрічці активності друзів

Патч backend 1.17.1 додає поле `posterUrl` до відповіді `/social/activity` для збережених та рекомендованих тайтлів.

Постери читаються разом із подіями з наявних записів бази даних, без окремого запиту для кожного фільму. Для подій дружби й тайтлів без постера повертається порожній рядок.

Зміна зворотно сумісна. Нових міграцій немає. Супутній інтерфейс: frontend 1.18.1.

Перед публікацією виконуються Go vet, тести, race detector і збірка.
