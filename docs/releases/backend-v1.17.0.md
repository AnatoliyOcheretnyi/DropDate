# Кіногеографія, персональні колекції та надійніші рекомендації

Мінорне оновлення API для frontend 1.18.0: нові способи знаходити фільми та продовжувати гру без втрати відповідей.

## Нові можливості

- API країн, світового кінокаталогу, персональних добірок і маршрутів із трьох фільмів.
- Повний кінопаспорт за всіма статусами, які означають перегляд; врахування країн спільного виробництва.
- Персональні колекції головної: випущені очікувані тайтли, перлини, нові країни та роботи улюблених акторів і режисерів.
- API нових релізів за останні три місяці.
- Продовження акінатора з виключенням відхилених припущень і збереженням відповідей. Старий формат запитів залишається сумісним.

## Якість рекомендацій

- Рейтинги країн враховують кількість голосів; добірки працюють і для невеликих кінематографій.
- Походження фільму відокремлено від регіону доступності сервісів.
- AI працює з реальними кандидатами, описами й метаданими. Якщо AI недоступний, використовується звичайне ранжування.
- Пік дня коректно використовує вже наявну історію смаку. Виправлено обробку помилок і оновлення кешів після змін у списках.

## Сумісність і перевірки

Нових міграцій бази даних для цього релізу немає. Додано регресійні тести кіногеографії, колекцій, рекомендацій та відхилених припущень акінатора. Перед публікацією виконуються Go vet, тести, race detector і збірка.
